# B站博主视频批量拆解与爆款分析技能 (Bilibili Creator Watch)

## 0. 核心定位
本技能扩展了单视频解析工具 `bili_watch` 的边界，支持**以博主/UP主为单位**进行多视频批量矩阵分析。专门用于：
- 拆解对标博主的爆款选题与标题套路；
- 分析博主视频的黄金 3 秒引入与情绪共鸣点；
- 提炼同赛道可直接套用的内容创作 SOP。

## 1. 触发与入参
当用户提出：
- “帮我分析一下这个 UP 主的内容/视频风格”
- “拆解一下 UP主 [UID/空间链接/代表作] 的爆款逻辑”
- “拉取这个作者播放量最高的 10 个视频并做对比”
时激活本技能。

## 2. 工具调用与工作流

### 第一步：获取 UP 主视频矩阵列表
在终端运行插件命令：
```bash
node /Users/wangzhiguang/Documents/deepseek-harness/default-workspace/bili-creator-watch/bin/bili-creator.mjs <UID或链接> --limit 5 --order click --format markdown
```
- 参数支持：
  - `--limit <数量>`：默认 5，最大建议 10~15；
  - `--order <排序>`：`click` (播放量最高/爆款), `pubdate` (最新发布), `stow` (最多收藏)；
  - `--keyword <词>`：空间内定向搜索特定系列。

### 第二步：选择核心爆款深入文本/分镜（可选串联 bili_watch）
对于播放量最高的 1~2 支代表作，可调用已有的 `bili_watch` 获取逐字稿与弹幕高潮：
```
bili_watch(bv="<BV号>", command="text", head=1200)
bili_watch(bv="<BV号>", command="danmaku")
```

### 第三步：标准化输出交付 (5大模块)
1. **博主基本画像**：粉丝量级、投稿频次、核心赛道、受众心智定位。
2. **爆款选题与标题模型**：
   - 选题公式（如：极限挑战、专业降维对抗、反直觉真相、开箱测评）；
   - 标题文案钩子拆解（好奇心差、情绪对立、权威背书）。
3. **内容节奏与黄金 3 秒结构**：
   - 前 3 秒如何留住观众；
   - 视频高潮与转折点设计（对照弹幕爆发点）。
4. **商业变现与互动设计**：
   - 植入方式与转化动作（评论区引导、抽奖、私域/店铺引流）。
5. **可复制的对标创作 SOP**：
   - 给创作者的具体落地建议（选题建议、拍摄手法、文案框架模版）。
